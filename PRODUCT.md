# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary audience is undecided. The initial experience is a solo user exploring simulated trading and automated strategies.

## Product Purpose

Inferred from the brief: provide a web app to explore trading and strategy bots. The first version demonstrates the workflow with a paper portfolio and synthetic market data.

## Positioning

An interactive paper-trading desk where users can inspect a simulated portfolio and control sample strategy bots in one place. This positioning is an initial assumption, not a confirmed product claim.

## Operating Context

Users review a market, inspect simulated positions and activity, and start or pause example bots.

## Capabilities and Constraints

Initial scope is a static web application hosted on GitHub Pages, with demo state stored in the local browser. Prices, balances, and bot performance are synthetic. No brokerage connection, live market feed, real-money execution, or investment advice is provided. A production data source and any future live-trading scope are undecided.

## Evidence on Hand

No verified market data, performance history, customers, or financial claims were supplied. Demo figures must be identified as synthetic.

## Product Principles

- Make simulation unmistakable.
- Keep portfolio state and bot controls inspectable.
- Let users pause automation directly.
- Do not present synthetic results as evidence of future returns.

## Accessibility & Inclusion

Use semantic controls, keyboard-visible focus, and responsive layouts.
